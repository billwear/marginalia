## My Quick Bio

I'm Bill Wear, and I've been using UNIX since 1974, Emacs since sometime in the 90's, and Org-Mode since 200?. 

Professionally, I have been a developer, a technical writer, a trainer, a product manager, and a developer advocate.  On the side, I have been a phreaker, shortwave listener, sewing enthusiast, and Trekkie.

I have production coded in bash, BASIC, C, C++, DBASE, FORTRAN, Javascript, Perl, PHP, Python and TIWAY.  I can also code in various assemblers, Elisp, Java, nroff and troff.  I also hold an Oracle Master's License, thought it is a bit dated. 

I have written production code for data acquisition systems, weapon systems production analysis, battle simulations, cost analysis tools, welding control systems, astronaut simulators, oil platform remote control systems, real-time virtual radiology lightboxes, educational scheduling programs, and adaptable user documentation publishing systems.  I have written lots of improved command-line UNIX/Linux utilities as a hobby project. 

I have publishing experience with Microsoft Word, Framemaker, Pages, OpenOffice/LibreOffice, and publishing directly from Org-Mode via org-export and pandoc.

I have written and published three complete books: "Programming the X-Window System," "Java Security," "Claude Opus 4.7," and ghostwritten seven others (titles confidential).

I have been active on the Internet since 1986 -- under the handles "stormrider" or "billwear" -- on BBS, IRC, Mattermost, and all of the various social media platforms.

I have had an active Website since 1994, although it has changed domain names and contents several times since then.

Notice I have said nothing about my personal life.  Let's keep it that way.
